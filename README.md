# ccarp-study

Personal study tracker for the Claude Certified Architect – Professional (CCAR-P) exam, booked for Dec 31, 2026.

`TRACKER.md` is the single source of truth for progress. It is updated from more than one machine and more than one Claude session.

## Rules for anyone (or any Claude) updating this repo

1. **Pull first.** Run `git pull` before every edit.
2. **Edit only `TRACKER.md` for progress.** Tick a task by changing `[ ]` to `[x]`. Add a short note after the task in italics if useful.
3. **Don't reword, reorder or delete tasks** unless asked. New tasks go at the end of the right week.
4. **Small commits, clear messages,** e.g. `W1: read exam guide ✓` or `W3: add flagged topics`.
5. **Push right away** so the other machine sees the change.
6. **Nothing work-related goes here.** No employer code, notes, documents or data. Study material only.
7. **No real manuscript content.** Use made-up test chapters for the study project.
